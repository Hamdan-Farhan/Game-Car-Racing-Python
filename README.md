🏎️ Pygame Car Dodger
لعبة سباق وتفادي عقبات بسيطة وممتعة مبنية باستخدام مكتبة Pygame. الهدف هو التحكم في السيارة
وتجنب الاصطدام بالسيارات الأخرى، البراميل، والحواجز التي تظهر على الطريق.
🚀 كيفية التشغيل

1-تثبيت المتطلبات:
تأكد من تثبيت مكتبة Pygame على جهازك عبر الأمر التالي:

Bash
pip install pygame
2-تشغيل اللعبة:
قم بتشغيل الملف الرئيسي:

Bash
python game.py

🎮 طريقة اللعب
التحكم: تعتمد اللعبة حالياً على النقر بالماوس:

النقر على الجانب الأيسر من الشاشة: تحريك السيارة لليسار.

النقر على الجانب الأيمن من الشاشة: تحريك السيارة لليمين.

الخروج: اضغط على مفتاح ESC أو Q لإغلاق اللعبة.


🛠️ المميزات التقنية
نظام العقبات العشوائي: تظهر العقبات (سيارات، براميل، حواجز) باحتمالات مختلفة لزيادة التحدي.

تحريك البيئة: يتم تحريك الطريق والأشجار الجانبية بشكل مستمر لمحاكاة سرعة السيارة.

تعدد المسارات: تظهر العقبات في مسارات محددة مسبقاً لضمان توازن اللعبة.


🏗️ التطوير المستقبلي المقترح
إذا كنت ترغب في تطوير المشروع أكثر، يمكنك العمل على:

إضافة نظام التصادم: حالياً الكود يحتوي على أقنعة التصادم (mask) ولكن يحتاج لتفعيل منطق انتهاء اللعبة عند اللمس.

دعم لوحة المفاتيح: إضافة التحكم عبر الأسهم (K_LEFT و K_RIGHT).

زيادة الصعوبة: زيادة قيمة المتغير speed تدريجياً مع مرور الوقت.

شاشة القائمة: تفعيل متغير home_page لعرض واجهة بداية اللعبة بشكل كامل.
